# Hyper-PiliPlus Revision

中文 | [English](README.en.md)

本项目是基于 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 的澎湃 OS 4（HyperOS 4）改版，专注于该平台的动画优化，改善一镜到底动画中页面转场、手势衔接与视频播放首帧交接的连贯性。

原有功能介绍、项目背景与致谢请参阅 [PiliPlus 项目](https://github.com/bggRGjQaUbCoE/PiliPlus)。本仓库在 [Hyper-PiliPlus](https://github.com/AritxOnly/Hyper-PiliPlus) 的基础上继续调整，感谢上游项目的开源贡献。

当前开发与验证以运行澎湃 OS 4 的 Android 设备为目标。仓库保留 iOS 工程供后续开发，不代表已完成 iOS 适配；不维护 Windows、Linux、macOS 桌面端。

开发、分析与测试统一使用 `./scripts/flutterw`，环境配置见 [Flutter 环境说明](docs/flutter-environment.md)，Android 打包方式见 [Android 发布说明](docs/android-release.md)。
