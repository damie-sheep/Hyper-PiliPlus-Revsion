# Hyper-PiliPlus Revision

[中文](README.md) | English

This project is a HyperOS 4 adaptation of [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus), focused on animation improvements for that platform: page transitions, gesture continuity, and the handoff to the first video frame.

For the original feature list, project background, and acknowledgements, see [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus). This repository builds on [Hyper-PiliPlus](https://github.com/AritxOnly/Hyper-PiliPlus). Thanks to the upstream projects for their open-source contributions.

Current development and validation target Android devices running HyperOS 4. The iOS project is retained for future development; iOS support has not been validated. Windows, Linux, and macOS desktop applications are not maintained.

Use `./scripts/flutterw` for development, analysis, and tests. See the [Flutter environment guide](docs/flutter-environment.md) and [Android release guide](docs/android-release.md) for setup and packaging instructions.
